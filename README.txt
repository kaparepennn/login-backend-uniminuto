PROYECTO LOGIN BACKEND
1. Importa base_datos.sql en phpMyAdmin.
2. Instala Node.js.
3. En esta carpeta ejecuta: npm install
4. Ejecuta: npm start
5. Abre http://localhost:3000
Prueba correcta: usuario1 / 12345
Prueba incorrecta: usuario1 / 99999
Estado de conexión: http://localhost:3000/estado
Nota: las contraseñas en texto plano son solo para reproducir el ejemplo académico del anexo; en producción deben almacenarse con hash seguro.
